# Sales Dashboard – Power BI

This project demonstrates data analysis and dashboard creation using Power BI.

## Tools
- Power BI
- Excel (.xlsx)

## Description
- Data cleaning using Power Query
- Data modeling with relationships (Star Schema)
- Interactive dashboard with KPIs and filters

## Files
- Sales_Dashboard.pbix : Power BI report
- AdventureWorks_Database.xlsx : Dataset
- dashboard.png : Dashboard preview
